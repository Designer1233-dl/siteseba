# Пропал из Интернета — загрузка на хостинг

Это готовая Node.js сборка сайта. Загружай на хостинг всё содержимое этой папки.

## Что внутри

- `server.js` — сервер и API;
- `index.html` — интерфейс сайта;
- `features.js` — безопасный пустой файл сборки;
- `package.json` — запуск через `npm start`;
- `data/` — чистая база.

## Как запускать

```bash
npm install
npm start
```

На хостинге укажи:

- язык: `Node.js`;
- entry/start file: `server.js`;
- start command: `npm start`;
- порт: переменная `PORT`, если хостинг её выдаёт автоматически.
