# Пропал из Интернета — Build 17

Готовая Node.js сборка сайта для загрузки на хостинг.

## Что загружать

Загружай на хостинг всё содержимое этой папки:

- `server.js`;
- `index.html`;
- `features.js`;
- `package.json`;
- `manifest.webmanifest`;
- `sw.js`;
- `assets/`;
- `data/`.

## Запуск

```bash
npm install
npm start
```

На хостинге:

- язык: `Node.js`;
- start file: `server.js`;
- start command: `npm start`;
- порт: используй переменную `PORT`, если хостинг её выдаёт.

## iPhone / Добавить на экран «Домой»

После загрузки на хостинг открой сайт в Safari на iPhone:

1. нажми «Поделиться»;
2. выбери «На экран Домой»;
3. нажми «Добавить».

Сайт уже содержит PWA-файлы:

- `manifest.webmanifest`;
- `sw.js`;
- `apple-touch-icon`.

На iPhone сайт будет открываться как отдельное приложение без обычной браузерной шапки.
