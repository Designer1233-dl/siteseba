# Пропал из Интернета

Главный файл сайта: `server.js` (Node.js), который отдаёт `index.html`.

Загрузи содержимое этой папки в отдельный GitHub-репозиторий и подключи его к Bothost как Node.js Web Service.

В Bothost укажи:

- язык: `Node.js`;
- точка входа: `server.js`;
- команда запуска: `npm start`;
- порт: `3000` (или значение переменной `PORT`).

Переменные окружения на Bothost:

- `PORT=3000`
- `DATA_DIR=/app/data`

При запуске сервер гарантирует наличие отдельного аккаунта администратора и сохраняет обычных пользователей, их сообщения и сессии. Регистрация пользователей открыта. Пользователь может создавать каналы и группы, вступать в них и отправлять сообщения, изображения и одноразовые фото. Панель администратора открывается кнопкой `☰` в шапке или кнопкой в профиле аккаунта `Vsevolod67`; сервер дополнительно проверяет роль `admin` на каждом moderation-запросе.

Перед публикацией открой `index.html`, найди в начале `<script>` строку `const API_BASE = 'http://localhost:8000';` и замени только адрес внутри кавычек на публичный HTTPS-адрес API из репозитория бота.
